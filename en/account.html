    Account & Login ✓ Live

    Link Discord with a code in Enter Coupon · move PCs with a device transfer key · one PC per account at a time · CloseBeta is for the Supporter role

    Your game account is tied to your device (the installed game) automatically — on first launch you can create a character and play right away. Linking Discord gives you a gift, a device transfer key for moving to a new PC, and is your way into the CloseBeta server. There is no password to remember.

    #What you can do

    • Pick a server from the list in game (PrebetaServer / CloseBeta)
    • Link your account to Discord with a 6-character code — you get a mail with 100 T Stone + a transfer key
    • Move to a new PC / reinstall with the transfer key and get your characters back
    • Get a new key when yours is lost or leaked (the old one stops working immediately)
    • Delete a character or your account, with time to change your mind

    #Picking a server ✓ Live

    The server list is shown in game on the Select Server screen — the launcher (DurangoLauncher) is only for updating the game, you do not need it every time.

    ServerWho can enter
    PrebetaServerEveryone (no Discord link needed)
    CloseBetaOnly players with the Supporter role on the server's Discord
    • CloseBeta checks your role live every time you enter the game — get the role and you are in right away · without it, a box tells you that you cannot enter when you try to enter the world · if the role is removed while you play, you are disconnected
    • Link Discord on PrebetaServer once and CloseBeta remembers the same device — no second code needed

    #Linking Discord ✓ Live

    1. On the server's Discord press the 🔗 link button → the bot opens a private channel with a 6-character code
    2. In game: Settings ▸ Account ▸ Enter Coupon ▸ type the code
    3. On success you get a mail from Discord with 100 T Stone and your device transfer key · the bot's private channel shows the key too (the channel is deleted within 10 minutes — write the key down)
    ItemValue
    Bot code6 characters · valid 10 minutes · single use
    Characters usedA–Z and 2–9 (no 0 O 1 I, to avoid mix-ups)
    Link gift100 T Stone (by mail)
    • Linked before the key system existed? The key mail arrives the next time you log in.

    #Moving to a new PC / reinstalling ✓ Live

    1. Install the game on the new PC and log in (a throwaway character is fine)
    2. Settings ▸ Account ▸ Enter Coupon ▸ type your transfer key (XXXX-XXXX-XXXX)
    3. Return to Title and log in again = your account's characters are back
    ItemValue
    Key format12 characters (XXXX-XXXX-XXXX), same character set as the bot code
    Works onEvery server linked to the same Discord (one key)
    Game version2.8.2 or newer (update through DurangoLauncher)
    • Whenever someone uses your key to move, the bot DMs you
    • Lost or leaked key: press 🔗 for a new code and enter it from your PC = you move instantly and get a new key · or press 🔑 New key in the bot's ticket channel (once per minute) — the old key dies on every server at once
    • There are no passwords any more

    ⚠️ Caution

    Your transfer key is like a house key — anyone who has it can move your account to their PC. Never share it.

    #One PC per account at a time ✓ Live

    An account plays one character on one PC at a time — if you log in from another PC (or with another character of the same account), the one already online is disconnected.

    #Deleting a character / your account ✓ Live

    DeletionTime before it is goneHow to cancel
    Delete character (character select screen)24 hoursCancel the deletion on the character select screen
    Delete account (Settings ▸ Account)7 daysLog in / create a character / cancel the deletion within 7 days = the whole account is restored
    • Characters waiting to be deleted still count toward the 3-per-account limit
    • Deleting the account also unlinks Discord

    💡 Tip

    To see your full account number, type /myaccount on Discord (only you can see the reply).

    #🔑 menu: code/key by DM ✓ Live

    In the Discord ticket room choose 🔑 Link code & transfer key → pick the server → the bot sends the 6-character link code + your current key by DM (no channel is opened) · this menu is for the Supporter role only · if your DMs are closed the bot answers with a message only you can see.
