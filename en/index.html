    Durango OffServer Guide

    How the server's systems work — what you can do, how, and the key numbers

    Welcome to the guide for Durango OffServer — a community-rebuilt server that lets you play Durango: Wild Lands again. This guide explains the game systems: what you can do, how to do it, and the key numbers on this server (some differ from the original game).

    • New here? Start with Getting Started and Account & Login
    • Use the search box at the top (press / to jump to it)
    • Every page, and many sections, carry a status label telling you whether that system is live on the server yet

    Status labels

    ✓ Live This system is in the version currently running on the servers

    ⏳ Not ready Finished in code but not deployed yet, or not built yet — the game may not behave as described

    ✓⏳ Live, but some sections on the page are not ready yet (see the section labels)
