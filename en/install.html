    Install and update ✓ Live

    Download only the launcher (PC or Android) — it installs the game, checks the files every time you open it and re-downloads only what is missing, broken or outdated

    You no longer download the game yourself — download only the launcher. It installs the game and checks the game files every time you open it; any file that is missing, broken or from an older version is downloaded again, just that file.

    #What you can do

    • Install the game from the launcher alone, on PC and Android
    • Update automatically when you open the launcher — you can skip versions, no need to update one by one
    • Repair missing/broken game files without downloading the whole game again
    • Clean files that don't belong to the game out of the game folder (PC)

    #PC ✓ Live

    1. Download DurangoLauncher.exe
    2. Put it in any folder — not a folder that needs admin rights such as Program Files
    3. Open it → the launcher creates a Durango Reborn folder next to itself and installs the game there (with a progress bar)
    4. When it's done, press Play

    Already have the game (unzipped earlier): put the new DurangoLauncher.exe over the old one in the game folder — the launcher keeps using that folder.

    💡 Tip

    Windows shows a SmartScreen warning → click More info → Run anyway (the launcher is not signed)

    #Every time you open the launcher ✓ Live

    • It asks the server for the latest version and checks every game file against that version's file list (a few seconds on an SSD · longer on a spinning hard disk)
    • Missing, broken or older-version files → downloads only those files · a new version is out = you are updated right there
    • Connection drops while downloading → the launcher retries by itself · close the launcher halfway → open it again and it continues; finished files are not downloaded again
    • Play unlocks after the check · press Verify Files or the refresh button to check again any time
    • The game is still running = the launcher skips the check that time (the game is using the files) → close the game and press refresh

    #Files the launcher deletes ✓ Live

    The game folder may only hold game files — anything that is not in that version's file list is deleted (empty folders too) every time you open the launcher, except:

    KeptWhy
    offserver.txtyour server/account settings — the launcher never edits or deletes it (missing = it adds the standard one)
    DurangoLauncher.exethe launcher itself
    .log filescrash logs to send to the team

    ⚠️ Caution

    Don't keep other files (pictures, mods, backups) in the game folder — they will be deleted. If the game folder is a shared place such as Desktop · Downloads · Documents or the root of C:/D:, the launcher deletes nothing and asks you to move the game into its own folder.

    #Android ✓ Live

    1. Download Durango Launcher and install it — the first time, allow Install unknown apps from this source
    2. Open the launcher → tap Download game — it checks your phone and picks the game build (ARM64 / ARMv7) that fits
    3. When it's installed, tap Play
    • Works on Android 8.0 or newer
    • Every time you open the launcher it checks the whole installed game — not the released file = Game files differ + a Reinstall button · new version = Update game button
    • Leftover installer downloads are deleted by themselves (an unfinished download of the latest version is kept so it can continue)
    • New launcher version = a bar appears in the launcher, tap it to update

    #Can I play without the launcher?

    Yes — starting the game directly works, but then nothing checks, repairs or updates your files. If your game is older than the version the server requires, the server won't let you in (see Account & Login) · the full game files are still available at GitHub Releases.
