    การจับสัตว์ ✓ ใช้ได้

    ตีสัตว์ให้เลือดต่ำกว่า 30% หรือให้มึน แล้วใช้สมุนไพรฝึกสัตว์จับ — จากนั้นฝึกในคอกให้เชื่องก่อนสร้างสายใย

    สัตว์ป่าเกือบทุกชนิดจับมาเป็นคู่หูได้ ขั้นตอนคือ ตีให้อ่อนแรง → จับด้วยสมุนไพรฝึกสัตว์ → ได้สายบังเหียน → ฝึกในคอกให้เชื่อง → สร้างสายใย แล้วจะได้ สัตว์เลี้ยง ที่พาเดินทาง ขี่ ช่วยสู้ และผลิตของได้

    #ทำอะไรได้บ้าง

    • จับสัตว์ป่าที่เลือดเหลือ ≤ 30% หรือ กำลังมึน/ล้มอยู่ (เลือดเท่าไรก็ได้)
    • ตีด้วยอาวุธประเภททุบหรือท่าหนักให้สัตว์มึนเร็ว
    • ฝึกสัตว์ที่จับมาในคอกฝึกสัตว์ แล้วสร้างสายใยเป็นสัตว์เลี้ยง

    #สิ่งที่ต้องมี ✓ ใช้ได้

    ไอเทมเลเวลใช้ทำอะไร
    สมุนไพรฝึกสัตว์ระดับขั้นต้น1–19เครื่องมือจับ — ต้องอยู่ในกระเป๋า
    สมุนไพรฝึกสัตว์ระดับมาตรฐาน20–39〃
    สมุนไพรฝึกสัตว์ระดับสูง40–60〃
    คอกฝึกสัตว์ชั่วคราว / คอกฝึกสัตว์ขนาดเล็ก—ฝึกสัตว์ที่จับมาให้เชื่อง
    • เครื่องมือจับเสียความทนทาน 3 ต่อการลองจับหนึ่งครั้ง (สำเร็จหรือไม่ก็ตาม) · กดจับตอนสัตว์ยังไม่เข้าเงื่อนไข เครื่องมือไม่สึก

    #วิธีจับ ✓ ใช้ได้

    1. ตีสัตว์จนเลือดเหลือ ≤ 30% หรือจนมันมึน/ล้ม (ดูหัวข้อเกจมึนด้านล่าง)
    2. เล็งสัตว์ แล้วกดปุ่ม จับ — ปุ่มเปิดให้กดเสมอเมื่อมีเครื่องมือ เซิร์ฟเป็นคนตรวจเงื่อนไข
    3. ยืนนิ่ง 3 วินาทีระหว่างแถบเวลา (ขยับ = ยกเลิก)
    4. สำเร็จ → สัตว์หายจากโลกและได้ สายบังเหียน ของสัตว์ตัวนั้นเข้ากระเป๋า · ไม่สำเร็จ → ขึ้นข้อความพร้อมโอกาสที่ทอย ลองใหม่ได้หลังคูลดาวน์ 5 วินาที
    • ยังไม่เข้าเงื่อนไขจะขึ้น «ยังจับไม่ได้ — ตีให้เลือดต่ำกว่า 30% หรือทำให้มึนก่อน»
    • จับซากหรือสัตว์เฝ้ารอยแยกไม่ได้ · ต้องยืนใกล้สัตว์ · สัตว์บางชนิดจับไม่ได้เลย (ปุ่มล็อก)

    💡 เคล็ดลับ

    ถ้ายืนห่างจากสัตว์ที่เลือดต่ำ มันอาจฟื้นเลือดกลับเกิน 30% (ฟื้นหลังพ้นต่อสู้ 20 วินาที) — จับให้เร็ว

    #สัตว์ในสังกัดเต็ม ✓ ใช้ได้

    ถ้าสัตว์ในสังกัดครบเพดานแล้ว (เริ่มต้น 8 ตัว) กดจับจะขึ้นข้อความว่าสัตว์ในสังกัดเต็มทันที — ไม่มีแถบเวลา เครื่องมือไม่สึก · ปล่อยร่อนเร่บนเกาะเทมหรือปล่อยเป็นอิสระสักตัวก่อน แล้วค่อยจับใหม่ · สายบังเหียนที่ยังไม่ได้สร้างสายใยไม่นับ — รายละเอียดที่ สัตว์เลี้ยง

    #โอกาสจับ ✓ ใช้ได้

    • ตัวคูณเลเวลมาจาก (เลเวลตัวละคร + ทักษะในการจับ ÷ 10) − เลเวลสัตว์ ยิ่งสูงกว่ายิ่งง่าย · ต่ำกว่าสัตว์ 6 เลเวลขึ้นไป = เหลือ 2%

    💡 เคล็ดลับ

    จะจับสัตว์เล็ก ใช้ค้อนหรืออาวุธประเภททุบ ตีด้านหน้าหรือด้านหลัง — มักมึนตอนเลือดยังเหลือ 30–45% ทำให้จับได้ก่อนเผลอฆ่า

    #หลังจับได้: ฝึกในคอก ✓ ใช้ได้

    1. สร้าง/วาง คอกฝึกสัตว์ แล้วใส่สายบังเหียนลงคอก
    2. กดเริ่มฝึก — ใช้เวลา 60 วินาที · โอกาสสำเร็จเริ่มต้น 60% (สูงสุด 100%)
    3. ให้อาหารระหว่างฝึกเพื่อช่วย:
    อาหารผล
    อาหารสำหรับการฝึกสัตว์อเนกประสงค์โอกาส +10% · เวลา −30%
    อาหารสำหรับการฝึกสัตว์แบบรวดเร็วเวลา −50%
    เนื้อ / ปลาซิวเวลา −10 วินาทีต่อชิ้น
    1. ครบเวลากดรับผล: สำเร็จ → สัตว์เชื่อง ได้อันดับสุ่ม (S · A · B · C · D ตามที่ชนิดนั้นมี) · ไม่สำเร็จ → สัตว์หนีกลับป่า สายบังเหียนหาย
    2. ใช้สายบังเหียนของสัตว์ที่เชื่องแล้วเพื่อสร้างสายใย → กลายเป็นสัตว์เลี้ยง (เลเวลสัตว์ต้องไม่เกินเลเวลหมวดการอยู่รอดของเรา) — ต่อที่ สัตว์เลี้ยง
    • เวลาฝึกลดได้ไม่ต่ำกว่าครึ่งหนึ่ง
