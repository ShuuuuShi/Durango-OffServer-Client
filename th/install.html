    ติดตั้งและอัปเดตเกม ✓ ใช้ได้

    โหลดแค่รันเช่อตัวเดียว (PC หรือ Android) — รันเช่อติดตั้งเกมให้ ตรวจไฟล์ทุกครั้งที่เปิด ไฟล์ขาด/เสีย/เก่าโหลดให้เฉพาะไฟล์นั้น

    ไม่ต้องโหลดตัวเกมเองแล้ว — โหลดแค่ รันเช่อ (ตัวเปิดเกม) ตัวเดียว รันเช่อติดตั้งเกมให้ และตรวจไฟล์เกมทุกครั้งที่เปิด ไฟล์ไหนหาย เสีย หรือเป็นเวอร์ชันเก่า รันเช่อโหลดให้เฉพาะไฟล์นั้น

    #สิ่งที่ทำได้

    • ติดตั้งเกมจากรันเช่อตัวเดียว ทั้ง PC และ Android
    • อัปเดตเกมอัตโนมัติตอนเปิดรันเช่อ — ข้ามเวอร์ชันได้ ไม่ต้องอัปทีละรุ่น
    • ซ่อมไฟล์เกมที่หาย/เสียเอง โดยไม่ต้องโหลดเกมใหม่ทั้งก้อน
    • ล้างไฟล์ที่ไม่ใช่ของเกมออกจากโฟลเดอร์เกม (PC)

    #PC ✓ ใช้ได้

    1. โหลด DurangoLauncher.exe
    2. วางไว้ในโฟลเดอร์ไหนก็ได้ — ห้ามโฟลเดอร์ที่ต้องสิทธิ์ admin เช่น Program Files
    3. เปิด → รันเช่อสร้างโฟลเดอร์ Durango Reborn ข้าง ๆ ตัวมันแล้วติดตั้งเกมลงในนั้น (มีแถบบอกความคืบหน้า)
    4. ติดตั้งเสร็จ กด เล่นเลย

    มีเกมอยู่แล้ว (แตก zip ไว้เดิม): เอา DurangoLauncher.exe ตัวใหม่ไปวางทับตัวเดิมในโฟลเดอร์เกม — รันเช่อใช้โฟลเดอร์นั้นต่อ

    💡 เคล็ดลับ

    Windows ขึ้นหน้าเตือน SmartScreen → กด More info → Run anyway (รันเช่อไม่ได้เซ็นชื่อ)

    #ทุกครั้งที่เปิดรันเช่อ ✓ ใช้ได้

    • ถามเซิร์ฟว่าเวอร์ชันล่าสุดคืออะไร แล้ว ตรวจไฟล์เกมทุกไฟล์ เทียบกับรายการไฟล์ของเวอร์ชันนั้น (เครื่องที่ใช้ SSD ไม่กี่วินาที · ฮาร์ดดิสก์จานหมุนอาจนานกว่านั้น)
    • ไฟล์ที่หาย เสีย หรือเป็นของเวอร์ชันเก่า → โหลดใหม่ เฉพาะไฟล์นั้น · เวอร์ชันใหม่ออก = อัปเดตตอนนี้เลย
    • เน็ตหลุดระหว่างโหลด → รันเช่อลองต่อเอง · ปิดรันเช่อกลางทาง → เปิดใหม่ทำต่อ ไฟล์ที่โหลดเสร็จแล้วไม่ต้องโหลดซ้ำ
    • ตรวจเสร็จปุ่ม เล่นเลย ถึงจะกดได้ · กด ตรวจไฟล์เกม หรือปุ่มรีเฟรชเพื่อตรวจใหม่เมื่อไหร่ก็ได้
    • เกมเปิดค้างอยู่ = รันเช่อไม่ตรวจรอบนั้น (ไฟล์ถูกเกมใช้อยู่) → ปิดเกมแล้วกดรีเฟรช

    #ไฟล์ที่รันเช่อลบ ✓ ใช้ได้

    โฟลเดอร์เกมเก็บได้แค่ไฟล์ของเกม — ไฟล์ที่ไม่อยู่ในรายการไฟล์ของเวอร์ชันนั้นจะ ถูกลบ (รวมโฟลเดอร์ว่าง) ทุกครั้งที่เปิดรันเช่อ ยกเว้น

    เก็บไว้ทำไม
    offserver.txtไฟล์ตั้งค่าเซิร์ฟ/บัญชีของคุณ — รันเช่อไม่แก้ไม่ลบ (ไม่มีไฟล์ = ใส่ตัวมาตรฐานให้)
    DurangoLauncher.exeตัวรันเช่อเอง
    ไฟล์ .logบันทึกตอนเกมเด้ง ไว้ส่งให้ทีมงานดู

    ⚠️ ระวัง

    อย่าเก็บไฟล์อื่น (ภาพ ม็อด สำรองข้อมูล) ไว้ในโฟลเดอร์เกม — จะถูกลบ ถ้าโฟลเดอร์เกมเป็นที่รวมของ เช่น Desktop · Downloads · Documents หรือราก C:/D: รันเช่อ ไม่ลบอะไร แต่ขึ้นเตือนให้ย้ายเกมไปไว้ในโฟลเดอร์ของมันเอง

    #Android ✓ ใช้ได้

    1. โหลด Durango Launcher แล้วติดตั้ง — ครั้งแรกกด อนุญาตติดตั้งแอปจากแหล่งนี้
    2. เปิดรันเช่อ → กด ดาวน์โหลดเกม — รันเช่อตรวจสเปคเครื่องและเลือกตัวเกม (ARM64 / ARMv7) ที่เข้ากับเครื่องให้
    3. ติดตั้งเสร็จ กด เปิดเกม
    • ใช้ได้กับ Android 8.0 ขึ้นไป
    • ทุกครั้งที่เปิดรันเช่อ ตรวจตัวเกมในเครื่องทั้งไฟล์ — ไม่ตรงกับตัวที่ปล่อย = ขึ้น ไฟล์เกมไม่ตรง + ปุ่ม ติดตั้งใหม่ · มีเวอร์ชันใหม่ = ปุ่ม อัปเดตเกม
    • ไฟล์ติดตั้งที่โหลดค้างไว้ถูกลบเอง (ตัวที่กำลังโหลดค้างของเวอร์ชันล่าสุดเก็บไว้โหลดต่อ)
    • รันเช่อมีเวอร์ชันใหม่ = ขึ้นแถบบอกในรันเช่อ กดอัปเดตได้เลย

    #ไม่ใช้รันเช่อได้ไหม

    ได้ — เปิดตัวเกมตรง ๆ ก็เล่นได้ แต่จะไม่มีใครตรวจ/ซ่อม/อัปเดตไฟล์ให้ ถ้าเกมเวอร์ชันเก่ากว่าที่เซิร์ฟกำหนด เซิร์ฟไม่ให้เข้า (ดู บัญชีและการเข้าเกม) · ไฟล์เกมตัวเต็มยังมีให้โหลดเองที่ GitHub Releases
